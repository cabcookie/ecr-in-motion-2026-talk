Da ich kein echtes Outlook, Teams, SAP oder Manhattan an Quick anbinden kann, müssen wir genau solche simulieren. Ich denke daran, dass wir eine SQLite Datenbank bauen, auf die wir über einen Vite Server und somit ein Webfrontend drankommen und somit EMail, Teams, SAP usw. simulieren können, dann aber auch MCP Server dafür bauen, um die Daten auslesen zu können und somit Amazon Quick zur Verfügung stellen können als auch anderen Agenten, die andere Rollen simulieren können. Bis das dann bei mir aufschlägt und über die MCP Server in Amazon Quick bei mir sichtbar werden würde.
